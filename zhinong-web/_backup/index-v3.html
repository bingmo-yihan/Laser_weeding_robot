项目名片

基于贝叶斯优化的多模态感知与动态能量调控的智能激光除草机器人

所属一级学科：控制科学与工程 项目层次：创新一般项目 · 一般项目 实施周期：2026年1月 — 2027年4月 负责人：韩鹏兰（软件工程）· 指导教师：卫艺冉

项目简介

当前农田杂草快速生长、病虫害复杂，传统化学除草手段易导致农药过量、环境污染严重，且人工巡田效率低、反馈滞后，难以保障作物生长优势。

本项目构建基于贝叶斯优化YOLOv8的多任务视觉感知模型，融合多光谱与深度信息，实现杂草实时检测与生长点定位，并配合同轴瞄准与激光能量动态调控机构实现毫米级灭杀，依托数字孪生平台实现远程调控与作业闭环。项目旨在构建绿色、低耗、可持续的田间除草新范式，为作物生长提供无农药干扰的优势生态位。

项目价值

为什么选择激光除草机器人？

AI视觉 + 精准激光技术，从根本上解决化学残留与人工痛点，助农降本增效

杜绝农药残留

零化学品介入，不伤土壤与水体。调研显示连续使用化学除草剂3年以上，土壤板结可致小麦、玉米亩产下降8%—12%，激光除草从源头避免这一问题。

解决人工痛点

人工除草效率仅为0.5—3亩/人/天，农忙期劳动力缺口超过30%。机器人无人化自主作业，毫米级靶向灭杀，让农户从繁重除草中解放出来。

绿色可持续

响应国家农业绿色转型战略，避免除草剂残留引发的土壤酸化、盐渍化与板结，为作物生长营造无农药干扰的优生态位，符合碳中和导向。

研究意义 · 数据说话

杂草危害触目惊心，激光除草势在必行

杂草与玉米、小麦、花生等作物竞争养分、水分和光照，显著影响农业生产效益。人工除草效率低、劳动力紧张，难以适应规模化生产需求；化学除草每亩成本约30元，但长期施用危害深远。

长期化学除草：土壤有益菌群减少80%、氮含量下降40%，在90.9%的北方耕地中检测到除草剂残留引发的土壤酸化、盐渍化及板结
激光除草：杂草生物量减少≥97%、作物生物量提升≥30%，"无化学残留、靶向精准（误杀率<1%）、AI协同自动化作业"成为破解痛点的核心路径

针对河南本地"稀种 / 稠种"两种种植模式的真实农情，团队对装备进行了三项关键优化，确保产品"下得了地、进得了垄、护得住苗"。

  • 可伸缩底盘设计

    设备宽度由通用标准改为可伸缩底盘，兼容15—30cm行距，适配稀种与稠种双模式，避免碾压作物

  • 窄轮距橡胶轮方案

  • 机身宽度控制≤150cm

    优化机身结构，实现对窄垄沟与复杂地形的适配，降低设备成本与维护门槛

核心调研发现

  • 除草模式：郑州地区玉米、小麦、花生田普遍采用"化学除草为主、人工补除为辅"模式，化学除草易引发土壤板结、地力衰退及作物减产。
  • 隐性减收：化学除草每亩单次成本仅20—30元，但连续使用3年以上，土壤板结导致小麦、玉米亩产下降8%—12%，部分地块出现除草剂残留引发的出苗不齐，综合收益反而低于物理除草。
  • 种植模式：本地小麦、玉米分"稀种"（行距25cm左右）与"稠种"（行距10—20cm左右）两种模式，对底盘宽度提出差异化要求。
  • 设计优化：据此将设备宽度预设计改为可伸缩底盘，兼容15—30cm行距；采用窄轮距橡胶轮方案控制成本，无需履带式设计。

调研结论与设计反哺

问题一：农药隐性减收被低估

受访农户普遍反映，化学除草短期成本低，但3年以上连续使用土壤板结导致亩产下降8%—12%，综合收益低于物理除草 → 强化"绿色防控"产品价值主张

问题二：行距模式差异显著

稀种（25cm）与稠种（10—20cm）两种模式并存 → 设备宽度预设计改为可伸缩底盘，兼容15—30cm行距

问题三：幼苗损伤顾虑可解

出苗后15天内幼苗茎秆韧性较强，人工踩踏都不受损 → 采用窄轮距橡胶轮 + 控制行驶速度，压缩成本、无需履带

现有装备三大共性瓶颈

  • 识别精度不足：主流模型泛化能力弱，强光、阴雨天等复杂环境误判率高达15%，对小尺寸及被遮挡杂草识别精度偏低
  • 固定功率易伤作物：杂草幼苗期与成熟期能量需求差异达10倍，禾本科与阔叶杂草激光剂量需求分别为13J/mm与16J/mm，固定功率难以兼顾效果与安全
  • 复杂地形适配差：多传感器融合鲁棒性弱，缓坡等复杂地形下导航故障率高达20%，严重限制作业效率

本项目三大技术突破

  • 高精度识别：贝叶斯优化YOLOv8超参数自适应调优，作物—杂草区分精度提升至98%以上，误识别率≤3%
  • 动态化适配："杂草—环境—作物"三要素功率动态调控模型，替代固定功率输出，避免作物损伤，除草成功率92%—98%
  • 低成本落地：机身宽度控制在≤150cm，适配窄垄沟与复杂地形；轻量化机身、橡胶轮方案有效降低设备成本与维护门槛
